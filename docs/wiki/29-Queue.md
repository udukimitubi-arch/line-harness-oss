# 順番待ち（受付・事前受付・呼び出し）

お店の前での受付と、LINE からの事前受付を、1つの列で扱う機能です。
呼び出しやお知らせは、お店の LINE 公式アカウントから届きます。

## 使い始める

1. 管理画面の「予約 › 順番待ち › 設定・店頭QR」を開く。
2. 「印刷する」で店頭QRを印刷し、入口に貼る。
3. 事前受付の URL を、リッチメニューなどに置く。
4. 店のタブレットで「順番待ち」（今日の列）を開いておく。店内モニターを使うなら「モニター表示」も開く。

順番待ちを使えるのは、そのアカウントに LIFF が設定されていて、お客さんが友だち追加しているときだけです。

## お客さんの流れ

| 入口 | 受付していないとき | 事前受付済みのとき |
|---|---|---|
| 店頭QRを読む | その場で受付（到着済みで列に入る） | 「到着」になる |
| リッチメニューなど | 事前に受付（向かっている、で列に入る） | 待ち状況を表示 |

- 受付するとき、人数と席の希望（設定した場合）を選びます。
- 待ち状況の画面には、番号と「前に何組か」を出します。お客さんはこの画面から受付をキャンセルできます。
- 1人の友だちが同じ日に並べるのは1回だけです。

## 店側の操作

- **呼び出し**：呼べるのは到着済みの人だけです。呼んだ人より前にいた未到着の人は「飛ばし中」になります。その人が到着してQRを読むと、列の一番前に戻ります。
- **来店**：マイルが付きます。量はマイル画面の「順番待ちで来店」ルールで変えられ、初期値は50マイルです。来店タグを設定していれば、そのタグも付きます。
- **不在**：不在タグを設定していれば、そのタグが付きます。
- **再呼び出し／後回し（1つ後ろへ）／取り消し**
- **代わりに受付**：LINE を使わない人の分です。到着済みとして列に入り、LINE のお知らせは送りません。
- **受付の停止**：「事前受付を止める」と「受付をすべて止める」が選べます。

タグをきっかけにしたシナリオを作っておくと、来店後のお礼や再来店のご案内を自動で送れます。

## 自動で動くこと（毎分）

- 事前受付から決まった時間（初期値30分）たっても到着しない人は、自動でキャンセルします。
- 呼び出しから決まった時間（初期値10分）たっても来ない人は、「不在」にします。
- 前の日に残った列は閉じます。

## LINE のお知らせ

お知らせは、次のときに送ります。どれも1通ごとに、LINE の月の送信数を使います。

- 受付完了（設定で止められます）
- N組前（初期値3組前。0にすると送りません）
- 飛ばし（到着前に順番が来たとき）
- 呼び出し
- 自動キャンセル

## API

`/api/liff/queue/*`（お客さん）と `/api/queue/admin/*`（管理画面）があります。詳しくは OpenAPI の `Queue` タグを見てください。
